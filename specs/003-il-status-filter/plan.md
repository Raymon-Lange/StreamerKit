# Implementation Plan: IL Status Filter for Free Agent Suggestions

**Branch**: `003-il-status-filter` | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

---

## Summary

Surface ESPN injury status (`injuryStatus`) in all free agent suggestion outputs so managers
can make informed waiver wire decisions. Injured players are never hidden from waiver wire
suggestions — they appear with visible labels (CLI) and colored badges (web UI). For roster
optimization (start/sit recommendations), players marked `INJURY_RESERVE`, `OUT`, or
`SUSPENSION` are filtered out before scoring to prevent bad lineup recommendations.

## Implementation Steps

### Step 1 — `models/player.py`: add `injury_status` field

Add as the last field in `PlayerRecord` (must come after all fields with defaults since
`slots=True` preserves declaration order):

```python
injury_status: str | None = None
```

No other model changes needed.

---

### Step 2 — `collectors/espn.py`: extract in `player_to_record()`

In `player_to_record()` (line 70), add extraction before the `return`:

```python
injury_status = getattr(player, "injuryStatus", None) or None
```

Pass into `PlayerRecord(...)`:

```python
return PlayerRecord(
    ...
    injury_status=injury_status,
)
```

The `espn-api` `Player` object already parses `injuryStatus` from `playerPoolEntry.player.injuryStatus`
(confirmed in `.venv/.../espn_api/baseball/player.py:14,19`). No API change needed.

---

### Step 3 — `services/hitters_service.py`: pass through to row dict

In `_build_row()`, add to the returned dict:

```python
"injury_status": player.injury_status,
```

No filtering — all free agents remain in the candidate pool regardless of injury status.

---

### Step 4 — `services/pitchers_service.py`: pass through to row dict

In `_serialize_pitcher_row()`, add:

```python
"injury_status": player.injury_status,
```

No filtering — same waiver-wire logic as hitters.

---

### Step 5 — `services/optimizer_service.py`: filter before scoring

After `hitters = get_roster_players(...)`, add:

```python
_IL_EXCLUDE = {"INJURY_RESERVE", "OUT", "SUSPENSION"}
hitters = [p for p in hitters if (p.injury_status or "ACTIVE") not in _IL_EXCLUDE]
```

This mirrors the existing `_BENCH_SLOTS` guard already present in this file (line 11).

---

### Step 6 — `scripts/run_free_agent_hitters.py`: print label

Define label map at module level:

```python
_INJURY_LABEL = {
    "INJURY_RESERVE": "[IR]",
    "OUT": "[OUT]",
    "SUSPENSION": "[SUSP]",
    "DAY_TO_DAY": "[DTD]",
    "QUESTIONABLE": "[QUES]",
}
```

In the per-row print block (around line 48), modify the name line:

```python
inj = _INJURY_LABEL.get(row.get("injury_status") or "", "")
name_display = f"{row['name']} {inj}".strip() if inj else row['name']
print(f"{name_display} | {row['mlb_team'] or 'N/A'} | Pos: {positions} | Owned: {owned}")
```

### Step 8 — `frontend/src/components/Streamers.tsx`: add injury badge

**Add `injury_status` to the `StreamerRow` interface**:

```typescript
interface StreamerRow {
  name: string
  mlb_team: string
  tier: string
  streamer_rank: number | null
  percent_owned: number | null
  injury_status: string | null         // ← add
  recommendation: { action: string; reason: string }
}
```

**Add badge color map** (alongside existing `tierColor`):

```typescript
const injuryColor: Record<string, string> = {
  INJURY_RESERVE: 'bg-red-900 text-red-300',
  OUT: 'bg-red-900 text-red-300',
  SUSPENSION: 'bg-red-900 text-red-300',
  DAY_TO_DAY: 'bg-orange-900 text-orange-300',
  QUESTIONABLE: 'bg-yellow-900 text-yellow-300',

const injuryLabel: Record<string, string> = {
  INJURY_RESERVE: 'IR',
  OUT: 'OUT',
  SUSPENSION: 'SUSP',
  DAY_TO_DAY: 'DTD',
  QUESTIONABLE: 'QUES',
}
```

**Render badge inline after player name** (in the name `<span>` row):

```tsx
<div className="flex items-center gap-1.5">
  <span className="font-medium text-white text-sm truncate">{r.name}</span>
  {r.injury_status && injuryColor[r.injury_status] && (
    <span className={`inline-block px-1.5 py-0.5 rounded text-xs font-medium shrink-0 ${injuryColor[r.injury_status]}`}>
      {injuryLabel[r.injury_status]}
    </span>
  )}
</div>
```
