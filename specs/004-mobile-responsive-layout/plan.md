# Implementation Plan: Mobile Responsive Card Layout

**Branch**: `004-mobile-responsive-layout` | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/004-mobile-responsive-layout/spec.md`

## Summary

The StreamerKit dashboard uses a CSS grid that switches from 1-column to 2-column at the `md` breakpoint (768px). Two problems prevent reliable single-column stacking on small screens:

1. The `md` breakpoint is too narrow — tablets and small laptops (768–1023px) land in 2-column mode, which is cramped.
2. `DailyBrief` and `Profile` carry bare `col-span-2` with no mobile override, forcing an implicit second column in a 1-column grid and causing horizontal overflow.

The fix is three targeted Tailwind class changes across four lines in three files. No backend, API, or data model changes are needed.

## Implementation Steps

### Step 1 — Update main grid breakpoint (`App.tsx` line 17)

Change:
```
grid grid-cols-1 md:grid-cols-2 gap-4
```
To:
```
grid grid-cols-1 lg:grid-cols-2 gap-4
```

### Step 2 — Fix DailyBrief col-span (`DailyBrief.tsx` line 48)

Change `className="col-span-2"` on the `<Card>` element to:
```
className="col-span-1 lg:col-span-2"
```

### Step 3 — Fix DailyBrief internal grid breakpoint (`DailyBrief.tsx` line 50)

Change:
```
grid grid-cols-2 md:grid-cols-4 gap-4
```
To:
```
grid grid-cols-2 lg:grid-cols-4 gap-4
```

### Step 4 — Fix Profile col-span (`Profile.tsx` line 30)

Change `className="col-span-2"` on the `<Card>` element to:
```
className="col-span-1 lg:col-span-2"
```
