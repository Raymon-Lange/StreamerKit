# Implementation Plan: Expandable Streamer Pitcher Row

**Branch**: `005-streamer-row-expand` | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/005-streamer-row-expand/spec.md`

## Summary

Both SP Streamers cards (Today and Tomorrow) show a compact pitcher row. The API already returns richer data — season record, last-10 record, last-2 starts detail, opponent team and difficulty score — that the frontend simply ignores. This feature makes each row clickable so it expands inline to reveal that hidden data. The two components (`Streamers.tsx` and `TomorrowStreamers.tsx`) are identical in structure, so the expand/collapse logic lives in a new shared `StreamerCard` component that both wrappers delegate to.

No backend changes are required.

## Implementation Steps

### Step 1 — Create `StreamerCard.tsx`

New shared component. Accepts `tomorrow?: boolean` prop. Contains:

**Extended `StreamerRow` interface** — add to existing fields:
```
season_record:    string | null
last_ten_record:  string | null
last_two_starts:  string | null
opponent_team:    string | null
opponent_score:   number | null
```

**State**: `expandedName: string | null` initialized to `null`.

**Click handler** on each row `<div>`:
```
onClick={() => setExpandedName(prev => prev === r.name ? null : r.name)}
```

**Chevron indicator** — add to the right-side column alongside tier/rank:
```
<span className="inline-block text-gray-500 text-xs transition-transform duration-150"
      style={{ transform: expandedName === r.name ? 'rotate(90deg)' : 'rotate(0deg)' }}>
  ›
</span>
```

**Expanded section** — rendered conditionally below the compact row content when `expandedName === r.name`:
```
{expandedName === r.name && (
  <div className="mt-1 pt-1 border-t border-gray-800 grid grid-cols-2 gap-x-4 gap-y-1 text-xs text-gray-400">
    <span className="text-gray-600">Season</span>     <span>{r.season_record ?? '—'}</span>
    <span className="text-gray-600">Last 10</span>    <span>{r.last_ten_record ?? '—'}</span>
    <span className="text-gray-600">Last 2</span>     <span>{r.last_two_starts ?? '—'}</span>
    <span className="text-gray-600">Opponent</span>
    <span>{r.opponent_team ?? '—'}{r.opponent_score != null ? ` (${r.opponent_score})` : ''}</span>
  </div>
)}
```

Add `cursor-pointer select-none` to the row `<div>` so it feels interactive.

### Step 2 — Simplify `Streamers.tsx`

Replace the component body with a one-line render:
```tsx
import StreamerCard from './StreamerCard'
export default function Streamers() {
  return <StreamerCard />
}
```

### Step 3 — Simplify `TomorrowStreamers.tsx`

Same pattern with `tomorrow` prop:
```tsx

  return <StreamerCard tomorrow />
}
```
